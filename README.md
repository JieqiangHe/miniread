# miniread

> Paper reading used to mean a PDF on the left and a translation tab on the right; with AI in the browser, one file does both — and the PDF never leaves my machine.

A single-file PDF reader with side-by-side AI translation: open a paper, drag across a sentence, read the translation. GLM or DeepSeek with your own key, streaming replies with the model's reasoning shown inline. Lazy-rendered pages, thumbnails, keyboard navigation, light and dark themes. Nothing is uploaded.

**Live: https://jieqianghe.github.io/miniread/**
